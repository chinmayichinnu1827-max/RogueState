ROGUESTATE — PLAYABLE PROTOTYPE

IMPORTANT: This is a Unity prototype, not the finished Gameathon game. It creates a small 3D city and a playable mission when you press Play.

OPENING
1. Extract this ZIP once.
2. In Unity Hub choose Add > Add project from disk.
3. Select the folder named RogueState_Complete (the folder containing Assets, Packages, and ProjectSettings).
4. Open with Unity 6.3 LTS (6000.3.25f1) if available. Wait for imports to finish.
5. In the Project window open Assets > Scenes > RogueState.unity.
6. Press Play.

CONTROLS
WASD / arrow keys = move
E near the orange information marker = open The Silent Ledger mission
Click Report / Sell Info / Investigate / Keep to make a choice
Esc or Close = close the mission panel

If Unity reports input errors: Edit > Project Settings > Player > Other Settings > Active Input Handling > Both, then restart Unity.

If the project still cannot be added, verify that you selected the folder containing Assets, Packages, and ProjectSettings — not the ZIP or Assets folder alone.

The generated scene and scripts have not been verified by running Unity in this environment. If Unity shows an error, send a screenshot of the Console.
