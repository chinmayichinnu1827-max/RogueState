\#  RogueState



\### Every Choice Builds Your State.



RogueState is a persistent, open-world, choice-driven game developed by \*\*Altera\*\* for Gameathon 8.0.



The player is not forced into a fixed path. Every decision can change money, reputation, relationships, factions, missions, and the world itself.



\##  Core Idea



> \*\*Information is Power.\*\*



Players can discover, collect, trade, protect, or use information to create opportunities.



\##  Gameplay Loop



Explore → Discover Opportunity → Mission → Make a Choice → Reward / Consequence → World Changes → New Opportunities



\##  Gameathon Prototype



Our first playable prototype will demonstrate:



Player → Small Environment → NPC → Interaction → Mission → Choice → Consequence → World Reaction

\##  Development Vision



RogueState is designed as a persistent world rather than a traditional level-based game.



There is no single correct path.



Players can build their own identity through their decisions and actions.
